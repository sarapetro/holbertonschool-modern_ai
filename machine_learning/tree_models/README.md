# Tree Models

This project explores tree-based models in Machine Learning for classification and regression tasks using Scikit-learn.

## Topics Covered

- Decision Trees
- Random Forests
- Classification and Regression
- Overfitting and Underfitting
- Bias-Variance Tradeoff
- Feature Importance
- Model Training and Evaluation
- Hyperparameter Tuning

## Requirements

- Python 3.11
- NumPy
- Pandas
- Scikit-learn

## Installation

```bash
pip install numpy pandas scikit-learn
```

## Learning Objectives

- Understand how tree-based models make predictions.
- Implement classification and regression models.
- Evaluate model performance using appropriate metrics.
- Understand how hyperparameters affect model complexity.
- Reduce overfitting and improve model generalization.

## Technologies

- Python
- Scikit-learn
- NumPy
- Pandas
